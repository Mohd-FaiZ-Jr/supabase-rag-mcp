# Sample Banking RCA: Missing Transaction Reference

> Test document for RAG evaluation. This is not a real incident record.

## Incident

Transaction reference was missing after a successful money transfer.

## Root Cause

Reference generation occurred before transaction success was persisted. The success handler returned before the reference write completed, so the response contained no transaction reference.

## Corrective Action

Generate and persist the reference as part of the successful completion transaction, then return the persisted value to the client. Add an integration test for successful transfer responses.
